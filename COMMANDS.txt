STEP 1: SETUP (First Time Only)
--------------------------------

# Option A: Automated setup (recommended)
./setup.sh

# Option B: Manual setup
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# On Ubuntu/Debian, also install:
sudo apt-get install graphviz


STEP 2: ACTIVATE ENVIRONMENT
-----------------------------

# Every time you open a new terminal:
source venv/bin/activate


STEP 3: TRAIN THE AGENT
------------------------

# Start training (takes ~1-3 hours)
python train.py

# This will create a directory like:
# runs/run_20241126_120000/


STEP 4: VISUALIZE RESULTS
--------------------------

# Set your run directory (replace with actual timestamp!)
RUN_DIR="runs/run_20241126_120000"

# Generate all network diagrams
python visualize_network.py $RUN_DIR

# Create comprehensive training plots
python plot_fitness.py $RUN_DIR

# Create animated GIF of evolution
python visualize_evolution.py $RUN_DIR

# Watch the trained agent play
python demo_best.py $RUN_DIR


VISUALIZATION OPTIONS
---------------------

# View last network diagram while generating
python visualize_network.py $RUN_DIR --view

# Display plots after generating
python plot_fitness.py $RUN_DIR --show

# Fast animation (200ms per frame)
python visualize_evolution.py $RUN_DIR --fast

# Slow animation (1000ms per frame)
python visualize_evolution.py $RUN_DIR --slow

# Custom animation speed
python visualize_evolution.py $RUN_DIR --duration 300

# Create side-by-side comparison
python visualize_evolution.py $RUN_DIR --compare


DEMO OPTIONS
------------

# Interactive mode (trigger episodes manually)
python demo_best.py $RUN_DIR --interactive

# Run specific number of episodes
python demo_best.py $RUN_DIR --episodes 10

# Just analyze network structure
python demo_best.py $RUN_DIR --analyze

# Faster rendering
python demo_best.py $RUN_DIR --fast

# Slower rendering
python demo_best.py $RUN_DIR --slow

# No visual rendering (stats only)
python demo_best.py $RUN_DIR --no-render

FILE LOCATIONS AFTER TRAINING
------------------------------

After training, expect these files in runs/run_YYYYMMDD_HHMM/:

Configuration:
  - config.ini                    # Copy of NEAT config used

Genomes (pickled):
  - winner.pkl                    # Overall best genome
  - best_genome_g000.pkl          # Best from generation 0
  - best_genome_g010.pkl          # Best from generation 10 (saved every 10 gens)
  - ...                           # Best genome snapshots every save interval
  - checkpoint-0                  # Checkpoints every 10 generations
  - checkpoint-10
  - ...

Statistics (CSV):
  - fitness_history.csv           # Fitness per generation
  - complexity_history.csv        # Network complexity per generation

Statistics (pickled):
  - stats.pkl                     # Full statistics object

Visualizations (after running scripts):
  - training_plots.png            # Comprehensive 4-panel plot
  - fitness_plot.png              # Simple fitness graph
  - neat_evolution.gif            # Animated evolution
  - network_comparison.png        # Side-by-side comparison (if --compare)
  - networks/net_g000.png         # Network diagram gen 0
  - networks/net_g010.png         # Network diagram gen 10 (if saved)
  - ...                           # One per saved generation
